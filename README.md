## Selected work

| Project | What it is |
| --- | --- |
| [Udaan Scholarship Finder](https://github.com/sanskriti49/udaan-scholarship-finder) | A full-stack scholarship discovery experience with React, a Node/Express backend, authentication, eligibility and scholarship flows, resources, and application guidance. |
| [Weather App](https://github.com/sanskriti49/weather-app) | A React weather dashboard with protected weather views, city search, three-day summaries, and an interactive map built with Leaflet. |
| [Spam Detection](https://github.com/sanskriti49/spam-detection) | An SMS classification project using TF-IDF vectorization and a Multinomial Naive Bayes model to distinguish spam from ham. |
| [Sentiment Analysis](https://github.com/sanskriti49/Sentimental-Analysis) | A Flask-backed restaurant-review classifier that uses a Naive Bayes model to predict positive or negative sentiment through a web UI and API. |
| [React To-Do List](https://github.com/sanskriti49/todo-list-using-react) | A responsive task manager for adding, editing, completing, and deleting tasks with React state and effects. [Live demo](https://sanskriti49.github.io/todo-list-using-react/) |
| [Portfolio](https://github.com/sanskriti49/my_portfolio) | A personal portfolio site for presenting projects, skills, and contact information. [Live site](https://sanskriti49.github.io/my_portfolio/) |
| [Shopping List API](https://github.com/sanskriti49/vercel-shopping-list-app) | A small Express API for creating, reading, updating, and deleting product listings, deployed on Vercel. [Deployment](https://vercel-shopping-list-app.vercel.app/) |
